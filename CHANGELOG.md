# Changelog

All notable changes to this project are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.0.2]

- Settings tab no longer reads `Plugin.settings`, which exists only in Obsidian 1.13.0 and newer.

## [1.0.1]

- Stop using `workspace.revealLeaf`, which needs a newer Obsidian than the declared `minAppVersion`.

## [1.0.0]

- Initial release: every todo in your vault on one page, grouped by note and ordered by last update, with filtering, search and checking off in place. Works on desktop and mobile.

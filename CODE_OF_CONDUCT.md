# Code of Conduct

We want this project to be a welcoming place for everyone.

## Our standards

- Be respectful and patient. Assume good intent.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.

Not acceptable: harassment, insults or personal attacks, discriminatory language, publishing others' private information, and other conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Maintainers may remove, edit or reject comments, commits, issues and other contributions that violate this code, and may temporarily or permanently ban contributors for behaviour they judge inappropriate.

To report a problem, contact the maintainer privately through their GitHub profile. Reports are handled confidentially.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
